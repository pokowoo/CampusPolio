Google ID Token 발급 테스트

Google 계정으로 로그인하면 ID Token을 발급받아 복사할 수 있습니다. 이 페이지는 토큰을 서버로 전송하거나 저장하지 않습니다.

Client ID를 입력한 뒤 로그인 버튼을 생성하세요.

복사한 토큰을 CampusPolio의 POST /api/auth/login 요청 본문에 넣으면 됩니다.

주의: Google Cloud Console의 OAuth 클라이언트에서 실제 실행 주소를 승인된 JavaScript 원본에 등록해야 합니다. 예를 들어 http://localhost:5500입니다. Client Secret은 입력하지 마세요.

실행 방법: 이 파일이 있는 폴더에서 python -m http.server 5500 실행 후 http://localhost:5500/google-id-token.html에 접속하세요.
